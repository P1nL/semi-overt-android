# Android 第一阶段范围与验收

状态：2026-10-16 范围已确认，1A 与 1B 离线版本已实现并通过下述验证。
真实后端和复杂 GPU 动效不在本次交付内。

## 目标与依据

先做设备上可操作的阅读闭环：发现文章 → 阅读 → 返回原位置。
沿用现有 SO.pen 的移动端视觉与导航；不使用 WebView 套壳，不把桌面布局缩小照搬。

2026-10-16 检查到的工程基线：Kotlin、Jetpack Compose、单 app 模块、
包名 com.semiovert.app、minSdk 26、compileSdk/targetSdk 37。
默认页面已经由用户运行成功，本阶段不升级构建工具来追求“最新”；仅为 API 37 设备测试将模板 Espresso 从 3.5.1 调整至 3.7.0。

## 第一阶段范围

### 1A：首页与阅读闭环

- 建立基础颜色、排版、间距、安全区域及手机明暗主题。
- 共享文章卡片覆盖有封面、无封面、长标题、无摘要。
- 首页使用明确标注的本地示例数据；常态不自动滚动，不重复文章凑数量。
- 阅读页按当前稿从右侧进入，不采用旧稿的卡片展开方案。
- 阅读支持正文、目录开关及标题滚出后的底栏状态；不新增设计中没有的返回按钮。
- 系统返回先关目录，再退出阅读，恢复来源列表的筛选条件、文章位置和滚动偏移。

### 1B：一级页面与共享导航

- 首页、分类、我的为主要场景；搜索保留独立入口并参与主圆导航。
- 主圆长按仅显示其他页面，松手命中才切页；未命中取消，当前页不重复入栈。
- 提供可点击、可读屏的同等入口，不另造常驻底部 Tab 栏。
- 分类首次进入默认 <3 min，短按主圆循环 <3 min → 3–8 min → >8 min。
- 从阅读返回分类时恢复原栏目和滚动位置，不再次重置默认值。
- 搜索支持输入、文章/作者结果及空结果；本阶段只搜索本地示例数据。
- 我的先完成未登录状态，不把登录、注册伪装成已接入，不放无反馈的假操作。

## 项目结构

保留单个 Gradle app 模块，按职责分包，不提前拆多模块或创建通用框架。
包根目录为 app/src/main/java/com/semiovert/app/。

- MainActivity.kt：原生入口。
- navigation/：页面、返回栈、来源与恢复状态。
- core/designsystem/：主题、基础组件、语义和触控规则。
- core/model/：Article、Author、阅读时长等最小模型。
- core/data/：本地示例文章及来源说明。
- feature/home/、category/、search/、reader/、profile/：页面及各自状态。

页面渲染状态并上报事件，页面状态由对应 ViewModel 管理。
导航和列表恢复有明确且唯一的状态所有者，不在各页复制全局状态。
按需加入原生导航和生命周期依赖，不一次性加入网络、数据库、DI 和缓存全家桶。

## 视觉与动效边界

- 当前 SO.pen 页面和共享组件为依据，归档画板仅作历史参考。
- 首轮对照：YMQs2 首页、e9e5TS 分类、ltfFa 阅读、OxflH 未登录我的。
- 不恢复已归档的首页立方体、眼睑开场。
- 保留大封面、薄荷/杏色卡片、圆角和信息层级，不擅自改成普通资讯列表。
- 画板像素不是跨设备固定 dp；按实际设备处理长标题、大字体和系统安全区域。
- 第一阶段先完成可操作布局和基础转场；普通平移/缩放不宣称为实体后弯或收卷。
- 独立圆拉断、拖动、重连、完整身份像素开场、实体曲面文章流后续专项实现。
- 设计文件并存旧的封面四阶段说明及较新的“全程可见、仅改变模糊强度”说明。
  实体曲面实施前先对齐此细节，本阶段不擅自定死着色器行为。

## 验收与完成条件

- 一次 debug 构建及针对变化的必要状态测试。
- 设备走通首页 → 阅读 → 目录 → 返回，分类 → 阅读 → 原位返回，
  搜索切换文章/作者及空结果，主圆切页及未命中取消。
- 检查长标题、无封面、列表恢复、系统返回、安全区域、基础明暗主题和大字体。
- 自动化与人工/设备证据分开记录，不将示例版本写成后端联调或真实登录验收完成。
- 完成约定闭环后停止，不追加通用测试矩阵、无关重构和额外平台适配。
- 提交和推送另行确认；初始化仓库的授权不自动延续。
