# Android 页面实现状态

页面基线核对：2026-10-16；统一堆叠、上提阅读与场景动效更新：2026-10-20。对照 Android 源码及本轮确认的交互设计稿。

## 已补齐：离线页面与交互

| 分组 | 当前可体验内容 | 边界 |
| --- | --- | --- |
| 首页 / 分类 / 搜索 | 首页保留弧形队列，左上进入并以真实第 1 张居中，继续下行 900ms 退场；分类前景先退出、后排先进入；搜索文章共用分类堆叠与上提，作者行不变；阅读返回恢复来源状态 | 本地原创示例；不再立方体翻转或曲面弯折；空搜索全量展示保留 |
| 阅读与目录 | 正文、目录定位、底栏标题、透明顶栏；同款卡片上提连续展开、取消回弹及来源原位返回 | 非最终富文本实现；转场不代表服务器文章加载完成 |
| 登录 / 注册 | 输入、错误提示、示例资料、进入演示身份 | 不认证、不注册、不上传；密码不持久化 |
| 密码恢复 | 示例邮箱、演示验证码校验、设置密码、结果页和返回登录 | 不发邮件，不修改真实密码 |
| 我的 | 删除左上“我的”；共享头像迁移、身份容器右滑、容器内像素封面、逐字信息、记录渐显、同款公开文章堆叠与上提 | 演示身份不等于真实账号；设置按钮固定在源头像下层 |
| 作者主页 | 搜索作者 / 阅读作者进入、公开文章、只读记录汇总 | 不显示设置或编辑入口，不读取本机快照 |
| 编辑资料 | 点击本人身份区进入；昵称、账号、简介、内置头像与封面；保存 / 放弃 | 只保存本机展示偏好，不上传图片 |
| 设置 | 外观、本地记录开关、清除确认、账号入口、退出演示身份 | 不调用服务器登出 |
| 导航位置 | 拖动安全区预览、左中右替代操作、保存 / 取消 | 保存相对坐标；主圆和扇形随位置调整；未做独立小圆 |
| 记录 | 折叠 / 展开、月历、年月选择、日期详情、每日汇总 | 明确标为内置数据；汇总不称为当天新增 |
| 快照与 Diff | 默认关闭；本人开启确认后显示内置增删和 Diff；清除确认 | 只演示版本，没有真实编辑器采集或账号历史 |
| 通用状态 | 加载、空内容、失败、不可见、不存在和重试恢复预览 | 从设置进入，明确标示演示，不伪造请求 |

## 入口

- 我的 → 登录 / 创建账号 → 进入演示身份。
- 我的右上角设置 → 外观、导航位置、记录、重置密码、状态预览。
- 已登录演示的头像 / 昵称身份区 → 编辑资料。
- 搜索作者结果或阅读作者区域 → 作者只读主页。
- 记录标题旁箭头展开月历，年月始终可点且不带箭头。
- 日期 → 汇总 / 文章增删 → Diff 抽屉；年月与确认抽屉均确定在左、取消在右。

## 已保留的交互修正

- 阅读页有独立背景；从同款卡片展开进入时使用共享位置和真实目标排版，不再叠加右侧滑入。其他层级页保持原导航方式。
- 主圆长按没有全页模糊、蒙白或调暗。
- 深色页面与弹层底色为 #191a1c；保留卡片 / 按钮语义色。
- 从搜索进入二级页时清理输入焦点、隐藏键盘，避免重建后抢先消费返回。
- 个人封面限制在身份容器内部；所有顶栏无整条底板，系统图标按页面背景保持对比度。
