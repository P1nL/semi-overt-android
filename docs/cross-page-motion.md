# 跨页转场协调

主页面（首页、分类、搜索、我的）使用同一套交接规则，保留停稳布局、阅读行为与手势弹簧；主要运动元素拥有各自完整的 1000ms 时间窗口，错峰重叠而非串行累加。

- 路由切换时同时保留新旧页面，每个页面的动画注册在它自己的 Navigation Compose transition 上。
- 旧页先开始退场；从退场中点开始与新页进场重叠，页面背景和界面元素在这一段交叉淡化。重叠时长为 `min(旧页退场时长 / 2, 新页进场时长)`，当前为 450–750ms。
- 新旧页面独立提供 `LocalFlowRoll`、`LocalFlowPhase`、`LocalProfileEntryProgress`，不再共享并重置一个全局进度。
- 首页退场仍为此前明确指定的 900ms。首页到分类总长为 1630ms（900 + 1180 - 450），首页到个人页为 1950ms（900 + 1500 - 450）。
- 导航条目等所有已注册动画完成后才恢复 `RESUMED`；交接期间阻止重复点击，返回键等待本次交接完成，不将动画强制归零。
- 设置、账户、作者等二级页统一使用 320ms 配对推入/返回：前景页整页滑动，背景页做 1/5 宽度位移和轻微透明度变化。返回不重播主页面场景进场。
- 阅读页保留现有卡片共享元素展开，不叠加通用页面滑动。
- 系统关闭动画时直接切换，无交接延迟。

## 头像位置交接

- 首页/分类的右上头像、搜索的左上头像、已登录个人页的 76dp 头像，共用独立的 `IdentityTransitionHost`。每次转场匹配本次新旧页面的真实布局位置和尺寸，只在覆盖层绘制一份共享头像。
- 头像以独立 1000ms 和 `SoSceneEase` 运动，完成时与目标位置对齐；不再将上一次进入个人页的起点当成下一次退出的终点，也不读取由多个页面共同写入的开屏坐标。
- 圆形底色只由共享头像自身绘制，导航按钮外层不另画圆盘，因此起点不留底色、终点不提前出现底色。
- 40dp 与 76dp 之间用共享边界的整体缩放绘制圆框和内部图标；图标保持圆框尺寸的 48%，不把返回页的 40dp 控件先重测成小头像再移动。进入放大、返回缩小均与位移共用同一条 1000ms 进度，只绘制当前目标的一份头像。
- 搜索页在共享交接期间不再额外平移头像按钮，避免共享位移叠加第二段偏移。开屏归位、非导航头像和未登录个人页引导保持原逻辑。
- `IdentityTransitionTest` 用实际渲染像素验证“首页 → 个人页 → 搜索 → 个人页 → 首页”的单头像、方向和最终落点连续性，并检查真实首页/搜索按钮没有残留或提前绘制的圆形底色。

## 舒缓的一秒主体运动

- 场景位移采用 `CubicBezierEasing(.42, 0, .58, 1)`，半程约完成一半位移；不改按钮、开屏、阅读等局部效果的旧缓动。
- 首页进场、分类和搜索队列：单卡各运动 1000ms，整组错峰跨度 180ms，场景共 1180ms。首页既定 900ms 退场单独保留。
- 搜索输入区：完整 1000ms，不随队列错峰缩短。
- 个人页：身份卡片在 0–1000ms 移入；封面 120–900ms、文字约 220–940ms 重叠展开；队列在 320–1500ms 进入，各卡同样保留 1000ms；整页共 1500ms。未登录引导主体也使用完整 1000ms。
- 首页圆弧循环首尾：离屏路径从 `|distance|=4` 平滑接入，在 `5` 前完成离屏，替代旧 `4.65–5` 的急促冲出；停稳仍为中间一张加两侧各四张，卡片不透明、身份和循环顺序不变。

实现：`navigation/PageTransitions.kt` 与 `navigation/AppNavigation.kt`。
定向验证：`PageHandoffTest`、`PageTransitionTest`、`ProfileSceneMotionTest`。
