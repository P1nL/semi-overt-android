# 跨页转场协调

主页面（首页、分类、搜索、我的）使用同一套交接规则，保留停稳布局、阅读行为与手势弹簧；主要运动元素通常拥有各自完整的 1000ms 时间窗口，搜索进退场单独缩短为 750ms，错峰重叠而非串行累加。

- 路由切换时同时保留新旧页面，每个页面的动画注册在它自己的 Navigation Compose transition 上。
- 旧页先开始退场；通常从退场中点开始与新页进场重叠，页面背景和界面元素在这一段交叉淡化。重叠时长为 `min(旧页退场时长 / 2, 新页进场时长)`；未登录个人页使用独立 450ms 时间线。
- 新旧页面独立提供 `LocalFlowRoll`、`LocalFlowPhase`、`LocalProfileEntryProgress`，不再共享并重置一个全局进度。
- 首页退场仍为此前明确指定的 900ms。首页到分类总长为 1630ms（900 + 1180 - 450），首页到已登录个人页为 1550ms（900 + 1100 - 450），首页到未登录个人页为 900ms（900 + 450 - 450）。
- 导航条目等所有已注册动画完成后才恢复 `RESUMED`；交接期间阻止重复点击，返回键等待本次交接完成，不将动画强制归零。
- 设置及其子页、注册和找回密码使用 500ms 缓入缓出曲线配对推入/返回：前景页整页滑动，背景页做 1/5 宽度位移和轻微透明度变化。前景的不透明页面在主圆之上的绘制层随真实页面边界左滑覆盖，不等转场结束才隐藏主圆；嵌套页面按返回栈深度保持前后次序。返回不重播主页面场景进场。登录仍位于个人页，保留主圆。
- 其他作者主页复用已登录个人页的场景时间线及文章堆叠，去掉顶栏并保留主圆。即使访问者未登录，也不套用访客登录表单的 450ms 动画；系统返回仍回到来源搜索或阅读页。
- 阅读页点击作者时，若同一作者（含具体 authorId）已在当前返回栈中，直接回到该条目，不重复追加作者页；阅读页复用主圆切页的 400ms 整页向下滑出及不透明覆盖层，不瞬间卸载，作者页在下方按个人页时间线进场。同时丢弃被弹出阅读页的卡片反向转场来源；系统返回仍保留原卡片反向收回。主圆切页先移除作者／阅读等详情尾部，再保存和恢复一级页面状态；旧版本保存过的详情栈也收敛到实际目标一级页，避免切到搜索却再次显示阅读页。
- 这些右滑退出的二级页支持从屏幕中间向右滑动，达到距离或快速滑动阈值后触发原返回动画；不是跟手式转场。输入框选择、子控件已消费的手势与纵向滚动优先，一级页与阅读卡片返回不套用此手势。
- 未登录个人页直接包含登录表单，不再推入单独登录路由；登录成功后不透明表单层用 600ms 向下退出，露出已经就位的个人页，不再重播身份卡片及文章队列的横向进场。注册保留单独页面，成功后向下退出到个人页。密码显隐按钮使用网页端的眼睑与瞳孔造型，保留开合和自然眨眼，瞳孔固定居中，不跟踪鼠标或触点。找回密码的邮箱、验证码、新密码和结果合并在同一路由，账户表单去掉顶栏标题和返回按钮，仍保留系统返回及右滑返回。所有身份和密码操作仍是离线演示，密码、验证码不进入持久化状态。
- 阅读页打开及系统返回保留卡片共享元素展开 / 反向收回，不叠加通用页面滑动。从阅读页通过主圆主动切换到四个主页面时，单独使用 400ms 缓入缓出的整页向下滑出：移动完整视口高度，不缩成 48dp 位移，也不对阅读页淡出。目标页背景先就位在下方，阅读页在临时绘制层保持不透明；第 200ms 接入目标页原有场景进场，不先退回来源卡片。
- 系统关闭动画时直接切换，无交接延迟。

## 主题与导航位置

- 首页头像下方提供网页同款太阳／月亮轮廓按钮。手动切换浅暗主题会关闭“跟随系统”，以按钮真实中心为圆心，用与网页一致的 760ms、`cubic-bezier(.4,0,.2,1)` 向最远角扩散；内部直接绘制完整目标配色，外部保留旧画面，不叠加全页颜色渐变。只捕获一张旧画面，结束后释放；关闭系统动画时直接切换。
- 设置只提供“跟随系统”胶囊开关，关闭时保持当前实际浅暗外观，手动浅暗切换使用首页按钮。
- 导航位置页显示最近停稳的首页快照，不运行第二份可交互首页。底部半透明模糊区保留真实尺寸和安全区，主圆拖动范围与正式页面完全一致；只显示“保存位置”按钮，系统返回或右滑放弃未保存位置，辅助功能通过主圆的方向操作调整。

## 主圆图标交接

- 首页、分类、搜索、我的四个图标覆盖全部六组双向形变，统一使用 400ms 与 `SoSceneEase`。仅内部图标的对应轮廓、线宽和填充连续插值，不淡化或缩放主圆底色与阴影。
- 轮廓状态由 `WaveDeckOverlayHost` 持有，仅最新页面拥有绘制及切换目标权限。路由重叠或返回时复用当前轮廓；中途切换目标从当前插值形状继续，不重置成某个页面端点，也不叠画两份主圆阴影。
- 阅读进入及返回原卡片仍由正文阶段进度直接驱动页面图标与目录图标之间的正反形变，不改为独立 400ms 计时。小圆展开、回收和合入的既有编排不变；系统关闭动画时主页面图标直接落位。
- `ReadingIconMorphTest` 验证六组双向路径与中途接续；`ReadingOverlayTest.primaryIconMorphSurvivesOwnerChangeAndReturnWithoutChangingShadow` 验证真实页面绘制交接中的图标连续性、返回及阴影稳定性。

## 导航圆配色与选中反馈

- 页面色独立于全局 Material 主题：首页翡翠绿 `#00C98D`、分类橙 `#FF7A00`、搜索蓝 `#2962FF`、我的紫 `#A12BFF`。径向小圆未选中时直接继承当前主圆的背景与前景色，选中时以 180ms 过渡为对应页面色；仍连接主圆的部分保留来源材质，分离后显现选中色；固定到页面上的快捷入口保留目标页配色。
- 小圆选中缩放目标为 1.14，使用阻尼 0.55、刚度 420 的弹簧，支持滑选中途接续。标签使用加粗的轻圆体字形，保留原有出现时序；字体子集与许可证见 `navigation-label-font.md`。
- 小圆展开和回收使用原生 Canvas 液态颈部：连接两圆真实圆周的切向贝塞尔曲线随距离拉伸、变细并断开，回收时反向融合；连接前后均保持当前主圆材质，图标在分离后显现。不使用模糊、阈值滤镜或额外动画计时器。整组导航共用原来的单所有者覆盖层，连接处只覆盖颈部范围的阴影，不缩放、移动或重绘主圆内部图标。
- 仅滑过不改变主圆颜色和图标。松手确认切页后，主圆背景、前景色和内部图标同时跟随目标小圆的真实回收进度变化；图标不再等待目标页面挂载。取消与拖出固定快捷入口均不改变当前页面状态。
- 主圆颜色和图标由 `WaveDeckOverlayHost` 跨页持有，仅当前绘制所有者允许改目标。回收完成后新页面直接继承已到达的颜色和图标，不重启动画或闪回默认状态。其他入口切页时背景与前景色使用与图标一致的 400ms 和 `SoSceneEase`。
- 阅读沿用来源页面色，仅内部图标变形；主圆位置、尺寸、透明度、阴影和触摸语义不变。系统关闭动画时颜色与缩放直接落位。
- 定向单测：`NavigationCircleColorTest` 验证四页配色、图标对比度、回收交接及中途接续；`LiquidCircleGeometryTest` 验证包含/分离边界、颈部连续变细和实际径向方向；视觉效果由人工检查。

## 头像位置交接

- 首页/分类的右上头像、搜索的左上头像、已登录个人页的 76dp 头像，共用独立的 `IdentityTransitionHost`。每次转场匹配本次新旧页面的真实布局位置和尺寸，只在覆盖层绘制一份共享头像。
- 头像通常以独立 1000ms 和 `SoSceneEase` 运动，进入或离开搜索时缩短为 750ms，涉及未登录个人页时仍使用 450ms；搜索输入框跟随同一进度。完成时与目标位置对齐，不再将上一次进入个人页的起点当成下一次退出的终点，也不读取由多个页面共同写入的开屏坐标。
- 圆形底色只由共享头像自身绘制，导航按钮外层不另画圆盘，因此起点不留底色、终点不提前出现底色。
- 40dp 与 76dp 之间用共享边界的整体缩放绘制圆框和内部图标；图标保持圆框尺寸的 48%，不把返回页的 40dp 控件先重测成小头像再移动。进入放大、返回缩小均与位移共用同一条交接进度，只绘制当前目标的一份头像。
- 搜索页在共享交接期间不再额外平移头像按钮，避免共享位移叠加第二段偏移。开屏归位、非导航头像和未登录个人页引导保持原逻辑。
- `IdentityTransitionTest` 用实际渲染像素验证“首页 → 个人页 → 搜索 → 个人页 → 首页”的单头像、方向和最终落点连续性，并检查真实首页/搜索按钮没有残留或提前绘制的圆形底色。

## 舒缓的一秒主体运动

- 场景位移采用 `CubicBezierEasing(.42, 0, .58, 1)`，半程约完成一半位移；不改按钮、开屏、阅读等局部效果的旧缓动。
- 首页进场和分类队列：单卡各运动 1000ms，整组错峰跨度 180ms，场景共 1180ms。首页既定 900ms 退场单独保留。分类卡片在每张原有 1000ms 窗口后半段加入小幅越过落点再回稳的惯性，不延长 1180ms 整组时长，不改变手动拖动或其他页面的曲线。
- 搜索进退场统一：输入区与单卡各运动 750ms，卡片错峰跨度 150ms，整组共 900ms。首页到搜索总长为 1350ms（900 / 2 + 900），搜索到分类总长为 1630ms（900 / 2 + 1180）；两端导航时钟与共享头像同步更新，不提前截断卡片位移，也不改变其他页面的场景时长。
- 已登录个人页进场 1100ms、退场 1000ms：身份卡片在 0–1000ms 移入，封面 120–620ms、文字 200–680ms、日历 300–650ms、栏目标题 300–550ms 重叠完成。文章队列在 100–1100ms 同步移动，不再叠加第二轮卡片错峰，焦点卡保留完整 1000ms。未登录个人页表单独立使用 450ms，连同导航注册时钟一并缩短，不是仅加速表面位移而继续等待旧 1500ms。
- 首页圆弧循环首尾：离屏路径从 `|distance|=4` 平滑接入，在 `5` 前完成离屏，替代旧 `4.65–5` 的急促冲出；停稳仍为中间一张加两侧各四张，卡片不透明、身份和循环顺序不变。

实现：`navigation/PageTransitions.kt` 与 `navigation/AppNavigation.kt`。
定向验证：`PageHandoffTest`、`PageTransitionTest`、`ProfileSceneMotionTest`。
