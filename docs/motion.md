# Android 动效首版

首版实现日期：2026-10-17；首页弧形队列 / 分类波浪堆叠更新：2026-10-19；统一卡片上提、个人页与场景进退场更新：2026-10-20。首页保留弧线构图，分类、搜索文章和个人公开文章共享卡片与上提阅读能力，不恢复旧眼睑开场。

## 按需高刷与静止回落

- 触摸按下、拖动、键盘输入、滚动和前景动画期间请求 `MotionFramePolicy.TARGET_FPS=120Hz`。旧系统使用当前分辨率支持的档位；实际显示模式由系统选择。
- 所有手指释放，且连续 400ms 没有前景帧或滚动活动后，将窗口的 `preferredRefreshRate` 清为 `0`，支持的系统同时清除 DecorView 的帧率偏好。按住不动仍保持高刷；静止后再触摸立即重新请求。
- `AppMotionFrameRate` 汇总 Activity 与抽屉窗口，任意窗口仍在运动时共同保持高刷。主窗口停止、抽屉销毁时注销输入与滚动监听；Compose 根节点和历史纹理 Surface 不再单独常驻请求 120Hz。
- `MotionDemandFrameClock` 观察现有 Compose 帧请求，继续委托原生帧时钟。惯性、吸附、抬起、回落、主题与页面转场会持续续期高刷请求。编辑器 DOM 内部滚动、CSS 和 Web Animations 通过本地桥通知活动；背景 WebView 继续以 30 fps 绘制，不续期前景高刷。
- 动画按系统 VSync 与经过时间推进，不新增忙循环 / 8ms 定时器。静止内容不为凑帧而持续重绘；系统关闭动画的行为保持。
- 开屏期间在后台解析 Ghost `loop-cycle` 素材；进入星芒穿越阶段时，首页访客头像开始播放。首页、分类、搜索和登录表单的访客头像接续同一播放进度，持续循环，没有外圆或底色。页面头像只在绘制时读取播放进度，不续期前景高刷请求；应用进入后台时暂停，关闭系统动效或素材未就绪时显示静态首帧。
- 首页访客头像在原 56dp 点击区内将 Ghost 的绘制宽高放大 25%。仅首页 Ghost 以两倍像素宽高绘制到独立图层，再缩回既定尺寸以平滑边缘。头像随首页从星芒内显露，开屏不再绘制或移动身份图标。
- 刷新率偏好清除后，系统依据设备能力与当前显示策略选档。当前 API 37 模拟器提供约 60Hz 模式；实际高刷与降档通过真机显示状态检查。
- `MotionFramePolicyTest` 覆盖 400ms 窗口和多窗口按住／释放；`AdaptiveFrameRateTest` 使用真实应用帧时钟验证前景动画、后台曲线、窗口重建、抽屉和编辑器 DOM 活动。

## 应用内动画时长倍率

- 应用内 Compose 动画固定使用设计时长：系统 Animator 倍率为 0.5×、1×、2× 等非零值时均按 1× 播放，tween 时长与弹簧参数保持原值。
- `SemiOvertApplication` 为应用窗口安装 `AppMotionDurationScale`，只替换 Compose 的时长倍率，保留原生生命周期和 VSync。导航、开屏、阅读、主题、控件与继承父组合的抽屉统一使用这项策略；Activity 重建后仍然生效。
- 系统“关闭动画”（倍率为 0）仍然有效，并监听运行中的切换：Compose 动画直接完成，现有无动画导航、开屏跳过及可读列表降级保持不变。
- 不写入手机全局动画设置，不影响其他应用。桌面进入 / 退出应用、系统键盘等由 Android 管理的转场不在这项应用内策略范围内。
- `AppMotionDurationScaleTest` 用可控帧时钟验证 tween、弹簧在各倍率下的时长及关闭动画；`AppMotionPolicyTest` 使用真实应用窗口，验证 Activity 与抽屉的协程均继承同一倍率策略，并覆盖 Activity 重建。

| 登录 / 注册 | 未登录个人页的表单从下方滑入 400ms，普通返回时向右滑出 400ms。独立的注册和重置密码页使用 500ms 右侧滑入 / 滑出。登录或注册成功时，原表单向下退出 600ms 并露出已登录个人页 |
| 日历 | 400ms 从顶部展开 / 收起、箭头同步旋转；保留清晰的背景纹样，星期 15sp、日期数字 17sp、日期摘要 22sp；绿色选中底形在日期间弹性移动，首次选中 / 取消均柔和淡化 |

| 开屏 | 已登录、未登录共用四角星芒连笔：四条曲边同时绘制 700ms，横线穿过星芒并延伸后，用 2000ms 连笔写完 `Vert`；笔尖进入 V 时开始左移。完整字形停留 200ms，再用 800ms 从 t 沿原路收回并回到原中心；最后 1100ms 向前穿过星芒，原生星形开口与轮廓同步放大，显露真实首页。常规时长 4800ms；浅色黑线、深色白线，圆头与平滑圆角。开屏不显示 Ghost 或头像，也不等待头像快照。完成后返回和 Activity 重建不重播 |
| 细节 | 首页主题按钮触发 760ms 圆形扩散（同网页曲线），太阳／月亮轮廓 220ms 形变；跟随系统的外观更新保留 220ms 颜色过渡、表单错误高度连续变化；页面状态预览仅保留主文本和图标，300ms 交叉淡入淡出，使用状态选项切换恢复，不再显示副说明和独立重试按钮；其他按钮 / 开关保留原生反馈 |

冷启动跳过独立的系统纯底预览，实际应用窗口以已选主题绘制开屏。首帧已显示四处星芒起笔，随后按原曲线连笔；系统关闭动画时直接显示内容。

首页和 WebView 在星芒后方并行准备，起笔不等待它们首绘。绘制、书写、停留和回收共用原生动画时钟。回收结束后若首页布局尚未就绪，停留在完整星芒；网格图像在整段开屏背后准备，穿越前最多额外等 500ms。首页原有进场从回收完成时接入；开屏结束且首页进场完成后，背景循环才开始播放。

`BrandIntroArtwork` 保留四条星芒路径、完整开口、连笔路径及各自的测量器和片段缓冲；逐帧仅更新描线长度与变换。横线越过星芒尖端后保留一小段再转入 V，e、r 与 t 沿确认的紧凑连笔连续绘制。`BrandIntroMotion` 保留参考 Demo Hub 的七段书写曲线，并按实际路径长度计算开始左移的时间。星芒开口与轮廓共用中心和缩放，终点按屏幕最远角校验覆盖范围；下方首页由 0.93 倍推进至原尺寸，穿越结束后交还触摸。

启动体验使用非调试的 `preview` 构建，继承 Release 的完整优化并使用本机 debug 签名；Debug 构建用于调试 / 自动化测试。

## 首页弧形叠放卡片队列

- 连续滑动的位置通过 `State<Float>` 传给每张卡片，在 `graphicsLayer` 中读取和更新变换；组合阶段只观察可见性、离散叠放顺序和交互身份。卡片保留原弧线、惯性、吸附和升起／回落时长，文字内容不随每个位置采样重新组合。循环边界的返回副本保留独立轨迹，退场从最后实际绘制的位置接续。
- 阅读转场的布局坐标以引用保存；点击阅读时读取当前变换后的坐标，返回时仅为正在等待测量的目标卡片生成完整 `ArticleSource`。普通浏览期间不在每个文字定位回调里重复生成整套转场坐标。
- 首页普通绘制不录制快照；离场前录制一帧完整的首页画面，供主圆位置设置页使用。录制后开始转场，位图读回与转场并行。

- 浏览态右侧作者头像与静止中卡之间留 6dp，保留原头像直径（上限 76dp）。外层透明，圆内使用当前首页背景色；本地示例使用已有头像占位图形。
- 浏览头像改为手势周期控制（2026-10-24）：取消半隐藏及 7 / 6 / 4 速度分段。超过原 touch slop、真正开始拖动后，头像用 140ms 向右退场一次；整个拖动期间保持隐藏，中途减速或按住不动都不恢复，轻触不触发退场。途中经过的作者不挂载、不补播。
- 松手后，同一中间卡片连续稳定 120ms（窗口内位移不超过 0.025 卡位），且收束中已接近整数停靠位（距离不超过 0.08 卡位），才用 280ms 滑入最终作者；无需等弹簧尾巴完全结束。恢复后不再因余动重复收起，下一次拖动重新开启确认周期。头像入场中再次拖动时，从当前位置平滑退回；作者图片只在屏外替换，不让旧头像重新进场。浏览态在点击展开（含先让位）、阅读与页面离场时收起；无动画 / 横屏等原列表回退不变。
- 点击展开的作者头像：卡片保持原尺寸、原右侧 16dp 位置与升起轨迹；升起到 95% 后，被点击卡片的作者头像以 280ms 从右侧进入，不受浏览态稳定窗口影响。头像右缘对齐展开卡片右缘，优先放在卡片下方，间隔 14dp；底部安全区不足则放上方。头像顶部安全边界额外避开主题按钮的 48dp 点击区域并留出 14dp 间隔，两侧都不足时不显示，避免遮盖内容或导航。上下位置在本次升起开始时确定，退场期间也不跳位。开始拖动、点击另一张卡片或进入阅读时，旧展开头像用 140ms 向右退出；回到浏览后使用上述手势周期。头像在卡片层后方，不拦截拖动，外层透明、圆内使用首页背景色。

- 主导航进场 900ms：每卡完整运动 720ms，错峰跨度 180ms。卡片从靠近队列上端的左侧屏外斜向右下进入，接入后沿原弧线落位；斜入段与弧线的方向和速度连续。前方卡片先行，后续卡片在队尾跟进并保持后方层级，尺寸和透明度不变。最终真实排序第一篇停在焦点；主导航重新进入时恢复到第一篇，阅读返回及 Activity 重建保留原选择。
- **首页卡片退场为 900ms**，独立于分类与阅读时长。所有卡片从首帧沿原圆弧及下端边缘路径连续离场，按前后顺序使用约 425–900ms 的单段曲线，各自直接走到下端离屏点；前排先离屏，后排沿队列跟随。离场不循环补入新卡，层级、尺寸和透明度不变。跨页通常从第 450ms 接入目标页；已登录个人页从第 250ms 接入，未登录表单从首帧入场。旧页保留至轨迹完成。

- 点击展开（2026-10-21）：滚动焦点与展开状态分离，停在中间不自动上升、右移或触发倾斜。点卡片才向右上方抽出，右侧留 16dp；上升量按它与前一层卡片的间距计算，靠位移露出完整内容，不提升 zIndex、不遮挡原本在前面的卡片。一次只展开一张，点击另一张会收回旧卡；开始滚动立即取消展开目标，但保留该卡片的收回动画状态；按升起、右移后的实际显示位置判断离屏，不按原队列卡位提前移除。收回期间跨过循环边界时沿当前轨迹继续，完成后恢复正常循环位置，避免突然消失或跳到另一端。卡片顶部不添加标签。
- 首页升起阴影的高度、环境阴影透明度与投射阴影透明度都绑定同一升起进度；卡片本体不再叠加固定阴影，因此回落全程同步淡出，不在终点突然移除。
- 原地优先：先检查抽出后的卡片能否完整放入顶部安全区加 76dp、底部系统安全区加 86dp 与主圆位置预留之间。能放下则队列位置完全不变；否则沿原弧线仅移动到最近合法位置（320ms 单调让位），不强制居中，然后展开。让位和普通滚动阶段不触发倾斜。
- 展开时的近邻绕自身底边做 X 轴三维倾斜：第一邻卡 ±20°、第二邻卡 ±6°，更远卡片不倾斜；上半段后倾、下半段前倾，主卡保持正面。保留原卡片尺寸、基础圆环及文章顺序；不压扁、不放大卡片，不添加选中边框。
- 卡片宽度通常为屏宽 70%，最大 360dp，使用方形与 18dp 圆角。首页 11 个卡位各有不同的底色，法蓝 `#1F50D5` 仅分配一次。文章有图片封面时优先显示封面，图片未就绪或没有封面时显示该卡位的底色。标题、作者 / 阅读时长和日期集中在底部，按封面明度使用白字或炭灰字。阅读展开与返回沿用源卡配色；降级列表沿用相同的封面规则。顶部入口与导航主圆不参与队列运动；顶部栏和底部提示均无背景遮罩，卡片可延伸到它们后方，仅在屏幕边缘裁切。
- 11 篇原创示例按原文章顺序循环，上滑选择后面的文章，下滑选择前面的文章，最后一篇可继续到第一篇。每篇文章有稳定身份，不在切换途中换色；同一帧不重复绘制同一篇。基础圆弧保持中心 `(0.48w, 0.53h)`、半径 `(0.30w, 0.34h)`、角步长 `0.30`，以焦点为中心，将纵向偏移统一压缩为原来的 80%（包含两端斜向段）；焦点位置、卡片尺寸及每卡位拖动距离不变。第 -2.5 到第 2.5 个卡位沿压缩后的圆弧排列，上下两端分别在第 -5.4 到第 -2.5、第 2.5 到第 5.4 个卡位之间展开左侧斜向路径。边缘进度采用平方曲线，延后向左展开，停稳时中间一张及上下各五张可见，滑动时保留 10–11 张。上端从左上侧接入队尾，下端朝左下侧离开，相邻卡片保持横向、纵向重叠和原叠放顺序。两端纵向附加位移减至 48dp 与卡高 15% 的较小值，再参与 80% 压缩，使越靠边缘的卡片纵向间距越小；边缘段与中央圆弧切向连续，反向拖动沿同一路径返回。整张卡片离屏后停止绘制，在距离 ±5.5 的循环换端前完成离屏，不用透明度掩盖循环。
- 真实文章不足 11 张时，沿用首页色板补齐弧形队列。纯色卡随队列滑动，但不显示文字或作者头像，不能展开和阅读；页码只统计真实文章。
- 内容区均可上下滑动；位移直接跟随纵向手势，横向手势不换卡。松手速度达到 1.2 卡位 / 秒时，先按释放方向惯性续滑，使用指数衰减（frictionMultiplier 1、速度阈值 0.5 卡位 / 秒），起始速度最高 12 卡位 / 秒，快速甩动可继续滑过约三张卡片；减速后从当前位置和剩余速度接续弹簧，吸附到最近整数卡位。慢速释放直接按原规则吸附。吸附弹簧保持 dampingRatio 0.82、stiffness 105；再次按住立即打断续滑并接管当前位置，离开首页取消剩余惯性。不增加圆环 / 假卡片背景，非选中卡片仍按文章顺序叠放。
- 只有主动展开时才有主卡上移、邻卡逐级响应；邻卡使用三维前后倾斜而非平面旋转，不额外平移。倾斜使用独立弹簧并随距离降低刚度。主卡的两个位移轴使用同一 0–1 进度，保留原弹簧路径，上浮与取消选卡回落均在 900ms 完成；主队列原有收束参数不变，不重排文章。
- 使用系统 touch slop 避免轻触被当作滑动；半页交界处留 0.06 页的焦点迟滞，减少来回抖动。新的拖动可以中断收束并从当前画面继续，不排队播放旧动作。离开场景时丢弃邻卡弹簧余动，首尾循环的不可见卡片不携带旧动画重新出现。
- 第一次点击只展开，不进入阅读；卡片升起过程中或完成后，再次点击立即衔接阅读展开，不再等待升起达到 99.5%。阅读转场在点击时读取卡片与文字当前的变换后位置，不先跳到升起终点；阅读转场启动后继续拦截重复提交。阅读返回及 Activity 重建保留队列的实际位置（包括最小让位产生的小数位置），不自动展开。离开场景时取消未完成收束，从实际可见位置接续向下退场，不先跳回整数卡位。
- 使用原生 Compose 卡片、主卡 translationX / translationY、邻卡 rotationX / TransformOrigin(0.5f, 1f) 与轻量 shadowElevation；cameraDistance 为卡片像素高度的 8 倍，rotationZ 保持 0、缩放保持 1，不提升选中层级。数据保留 11 篇稳定身份文章，只组合原圆弧及尚未完全离屏的末端卡片，首尾回收发生在屏幕外，不创建首页 EGL Surface，也不生成文章位图快照。
- 辅助功能提供阅读、上一篇 / 下一篇及显式定位。系统关闭动画、字体大于 1.2 倍、横屏或内容区过矮时使用原可读列表，不恢复旧立方体或曲面首页。

## 分类波浪堆叠

- 当前时长内每篇文章只绘制一次，按文章身份保持首尾循环。保留各卡片原来的顶部位置与叠放高度，只向下延长卡片至视口底部，不把整组卡片下移；前后排等宽，滑动中也不做远小近大的缩放，文字保持同样字号，不用纵向拉伸文字来填充。卡片只保留顶部圆角，底边为直角；标题、作者与日期整体放在卡片左上角，距边缘 18dp。大号页码位于内容区顶部。分类复用卡片组件，保留独立的插画封面。
- 卡片宽度为内容区的 90%（上限 420dp，仍受短屏尺寸约束），加宽不改变原顶部位置与纵向层叠间距；分类封面只在最底部约 12% 做轻量渐进模糊，上方保持清晰。素材由 `tools/generate_category_covers.py` 离线生成，无滚动帧实时模糊。
- 参考网页端 `HomeShowcaseRail.vue` 的波峰 / 邻卡联动：前卡直接跟手，后排从同一帧开始响应，不再等待位移阈值。在连续队列位移外叠加明显波峰，第一、第二邻卡的波峰目标按网页 0.25 / 0.10 衰减，再向更深处继续衰减；每张卡片用独立的可重定向 Compose 弹簧跟随目标，形成近强远弱的起伏，而非整组刚性平移。不照搬网页的横向展开和旋转，保留移动端等宽纵向排列与底部连接。前卡完全越过屏幕底部后，才在不可见阶段切换到最后方，并清除旧波峰余动。
- 下滑位移与释放速度采用 1.25 倍增益，同等队列位移所需下滑行程约缩短 20%；上滑的手势行程标尺保持不变。跟随直接映射当前手势，不用延时任务逐张启动；快速换向立即反映到整条波形，不回放排队动画。
- 上滑沿同一连续路径反向运行：前排逐张升高，运行到后排的卡片向下回落，形成前升后降的波形。反向拖动不重置各卡片位置，也不另起一个排队动画；只由手势与松手余动驱动，不自动循环。
- 松手主队列保留 dampingRatio 0.86 / stiffness 95 的柔和厚重弹簧；邻卡波峰按网页 stiffness 120 / damping 25 / mass 1 换算为 Compose stiffness 120 / dampingRatio 1.14，独立跟随、平缓回落，换向直接重定向，不排队。只做 Compose 平移与层级变化，不增加第三方动画依赖、逐帧截图 / 背景实时模糊或分类 EGL Surface。
- 各阅读时长分别保存已确认的文章位置；阅读返回、Activity 重建与时长轮换恢复相应位置。共享转场开始时取消未完成拖动 / 收束并恢复最后确认的位置。
- 辅助功能提供上一篇 / 下一篇、明确文章定位与阅读。系统关闭动画、字体大于 1.2 倍、横屏或可用高度不足时退回可读列表；空筛选保持原空状态，不重新启用旧曲面。

## 同款卡片上提与个人页（2026-10-20）

- 分类、搜索文章、个人页公开文章统一全封面、上 18dp 圆角 / 下直角、顶部信息及底部短模糊。卡片内部居中短横线为 32×3dp，实际命中区 96×48dp；所有可见位置的卡片均可从把手上提阅读，普通点按后排卡仍用于选中。提交阅读时将该文章保存为队列前卡，返回落到其新的前景位置；短提取消不改变原选择。
- 超过 8dp 且向上位移大于横向的 1.2 倍才接管阅读手势，不劫持普通队列滑动。上提行程上限为 160dp，到达边界即自动接续阅读，手指仍按住也继续播放；边界前按 45% 松手或有效向上速度达到 900dp/s 提交。快速松手只决定是否提交；短提取消承接松手初速度使用原阻尼弹簧。
- 拖动展开时保持卡片原尺寸，封面、标题、文字信息和把手一起平移到上提边界；提交后文案沿二次减速曲线移至阅读锚点，封面淡出，作者头像随后出现。源 / 目标各自保持固定排版，文字图层负责字号及换行布局的交接。
- 分类前卡和阅读把手点按使用 540ms 转场：卡片从原位上移，文案与封面淡出同步开始；源卡停止绘制时一并隐藏其点击反馈，正文使用第 60–540ms 的窗口。手势上提从释放时的位置继续原时间线。自动转场在阅读锚点量好后开始，系统关闭动画时直接导航。
- 首页在选卡上浮后进入阅读，独立时钟为 630ms：标题和信息在前 300ms 匀速到位，正文在第 150ms 开始进入，与标题重叠 150ms；源卡容器、封面和阴影保持原尺寸、原位置，在前 420ms 淡出，其余首页卡片同步淡出。作者头像在 300–480ms 接入；升起中再次点击仍从当时的真实画面接续。
- 正文进入均为 480ms 缓入缓出：首页在 150–630ms、分类在 720–1200ms 从底部上升并显现；主圆图标同步跟随各自的正文进度。回卡时整体放慢 100ms，保持原来的相对错峰。首页收起共 580ms：正文与主圆从首帧开始退场，作者头像在约 218ms 淡出；标题与信息从约 181ms 匀速回落，约 544ms 归位。源卡及其余首页卡片从约 181ms 原地淡入，共享背景在收起结束后续播。堆叠页收起共 1200ms：容器在上提边界保持尺寸淡入，文案归入卡片后，整卡再平移落回队列。两处均保持原卡片尺寸、圆角和阴影，页头在返回进度降至 0.52 时独立淡入。
- 堆叠页每张非源卡片各自保留独立阻尼弹簧，按顺序跟随下落目标；取消或返回时保留当前位置和速度、反向弹性上升。源卡回落完成后也不卸载邻卡弹簧，允许最后的弹性余动自然结束，不瞬间归零。
- 上提期间，阅读转场副本与其余堆叠卡片共用同一绘制平面，按原队列层级排序；后排卡原地提起，不越过前排。原本在前面的卡片保持可见并弹性下落，不因阅读副本进入全局覆盖层而被遮住。仅提交阅读后更新队列选择，返回时落到新的前景位置。
- 页头、头像、搜索范围与作者数、大号页码、个人信息 / 记录 / 栏目标题、快捷入口等非卡片元素，在上提行程中就开始淡出，取消时随回落恢复。主圆保持不透明，随正文进度移动到目录位置，返回时原路回到浏览位置。
- 大号页码的斜杠与数字按可见字形顶部对齐。透明度直接作用于定位后的整行；取消提起时连续恢复。
- 文字转场固定源、目标各自的排版宽度与字体尺寸，通过图层等比例缩放、位移和两端排版交叉淡化完成；不逐帧插值文本排版宽度 / 字号，不再在行程中反复触发换行。日期分隔符也保留在固定的目标文本中，不在中途拼接跳变。
- 堆叠卡片的手势时间线在 0.55 进度到达上提边界，文案于 0.55–0.80 减速落位，作者头像在 0.80–0.90 淡入。返回保留原标题轨迹和卡片落点。
- 阅读主圆短按打开目录，长按及快捷入口逻辑复用浏览主圆。系统返回先用约 240ms 将实际阅读列表滚回顶部，再让已显示的正文沿原轨迹下滑淡出。源卡在文字回落前就绪时使用实时坐标，否则沿用进入时的坐标，不等待来源列表重新加载。正文已在顶端时立即开始收回，系统关闭动画时直接导航。
- 阅读预览与实际阅读共用布局和排版；源、目标以同一根坐标系测量，完整卡片封面取景不因个人页滚动裁剪而改变。实际阅读进入组合后移交覆盖层，不再次右滑。返回保留来源查询、筛选、选中项和列表位置。
- 已登录共享头像在 600ms 内从页头移到个人页的 76dp 落点，已登录内容比常规重叠起点提前 200ms 开始。首页、分类的右上头像入口无点击涟漪。身份区在本页进场的 0–700ms 从右侧进入。
- 封面按原图裁切从顶部滑入，580ms 落稳后设置按钮用 120ms 淡入；封面使用清晰原图退出。齿轮淡入时按落稳的封面裁切区域选定黑或白，之后滚动不变色。姓名、账号、简介的逐字显现在 100–340ms 完成，记录标题在 150–300ms 渐显。
- 公开文章队列在 0–700ms 同步进入，栏目标题在 150–200ms 淡入。栏目标题与右侧篇数复用“记录”栏样式，展开后的日期和汇总数字单独放大加粗。个人页保留整页滚动，公开文章视口仍为后排顶部空间加主卡高度的 70%；卡片拖动先滚动个人页，再切换队列。阅读返回不重播进场。
- 已登录个人页和作者主页各用 700ms 进场与退场。未登录表单从下方滑入，与头像同步运动 400ms；设置按钮在 280–400ms 淡入。未登录普通退场为 400ms。登录成功后原表单仍向下滑出，阅读、编辑和设置返回保留个人页状态。
- `ProfileSceneMotionTest` 验证一级导航的重叠交接与重新进入，不清空演示偏好；项目开启 `android.injected.androidTest.leaveApksInstalledAfterRun`，避免连接测试结束时由运行器卸载演示应用及其本地数据。其他使用偏好重置规则的测试仍应使用专用测试设备。
- 浏览及其他层级页顶栏保持独立悬浮控件；阅读页无顶栏和底栏，只保留目录主圆及系统返回。内容仍保留系统安全区。
- 系统关闭动画时直接落位；大字体、横屏和矮视口保留可读列表降级与点击阅读，不启用旧 EGL 曲面。
- 作者头像按作者 ID 独立匹配：搜索作者项（48dp）、阅读作者入口（24dp）与作者主页（76dp）共用真实头像，只有选中的作者参与移动和缩放。搜索交接为 750ms，阅读作者入口交接为 400ms；头像绘制层在不透明阅读页退出层之上。从阅读页主动再访已存在的作者页时，将作者信息滚回可见位置；普通返回保留原滚动状态。
- 作者页 / 阅读页转到用户页面时，作者头像与用户头像在移动中使用 `AvatarPixelFrames`：前 40% 由清晰转粗像素，中间 20% 在双方均为粗像素时转换身份，后 40% 逐渐还原用户头像；图片档位在后台准备，不逐帧生成位图。同一作者之间的移动不切换身份，系统关闭动画时不播放像素转换。
- 阅读作者入口、搜索作者项，以及设置页及从它进入的子页，点击释放后改为 400ms、10 粒的小范围火花；独立覆盖层使火花不被行容器裁切，也不随导航立即消失，不延迟点击回调。Material 控件复用自身交互源，禁用控件和取消的拖动不触发火花；确认 / 年月等弹窗使用各自窗口的覆盖层。未登录设置页移除“进入登录页”按钮，保留正常返回。
- 堆叠队列最多同时展示：搜索 6 张、分类 7 张、个人页 5 张。总数不超过可见数时，原前卡离屏后回到队尾；总数超过可见数时采用数据滑动窗口，后排补入窗口外下一篇，刚离开的前卡不立即回升。出场卡占一个可见名额，完全离屏后补位，不复制文章；反向拖动沿相同路径还原。
- 阅读把手用固定根坐标计算方向、位移和释放速度；队列已开始拖动后不再中途抢占。避免首卡向下加速移动时，把手的移动局部坐标把向下手势误判为向上阅读，导致半程中断。
- 分类与文章搜索在卡片下方共用同一套 `n/m`，可见字形顶部对齐搜索“文章 / 作者”栏底部（系统状态栏下方 124dp）。两页互切时，整行保持位置和透明度，数字用 360ms 上下滚动到目标页的实际计数。滚动文章、分类换组和文章搜索更新沿用这套数字动画。按字体实际字形扣除顶部留白，在栏目栏下裁切滚动数字，并以全部文章的最大位数预留数字槽位。作者栏只在标签旁显示小计数，首屏请求和翻页等待分别在结果区和列表末尾居中播放虚线环。
- 分类页内点按分类主圆或已固定的分类快捷圆，循环切换阅读时长分组。旧组退场 550ms、新组进场 750ms（完整切换 1300ms），每段包含 84ms 错峰；新组越过落点后回弹与归位约 370ms。拖动松手弹簧不变。
- 搜索输入草稿与已提交关键词分离：首次进入不展示卡片，作者计数为 `0`，文章栏的大号页码为 `0/0`；从分类进入文章栏时由共享数字滚动到 `0/0`。手动输入、修改或删空关键词不会立即替换结果，只有键盘“搜索”确认后才提交；点击“×”会直接清空输入，有已提交结果时执行结果退场和计数归零。确认空关键词也会清空结果并让计数归零。已提交关键词、搜索范围和队列位置仍随页面恢复。
- 切到作者栏时，文章结果和大号页码一起向左滑出，作者栏从右侧滑入；切回时方向相反。请求等待和空状态都随所在栏移动，搜索框和标签保持原位。
- 确认新搜索时，结果卡片进退场各 550ms，保留错峰和轻微回弹；初次搜索只进场，空结果不播放空队列进场。旧结果退完才替换数据，大号文章计数沿用共享滚动数字，作者按钮旁的数字使用 360ms 上下滚动更新；输入草稿或重复确认同一关键词不驱动数字变化。
- 搜索触发采用同步门闩和单调时钟节流：完整动画期间拒绝重复提交，不排队、不重启动画；不同关键词的有效提交至少间隔 1200ms，即使关闭动画仍生效。“×”重置不等待搜索冷却，但仍受动画门闩与范围切换锁约束，并重新开始下一次搜索的冷却；动画期间按钮禁用，已经没有结果时仅清空草稿、不重复播放。忽略首尾空格和大小写差异造成的重复提交。范围切换单独限制为至少 350ms，且不能与搜索提交动画重叠；离开页面取消尚未结束的提交动画并释放门闩。
- 分类阅读时长标签采用 18sp 粗体，居中对齐大号页码的可见字形，浅色用黑、暗色用白。换组时从原标签经 280ms 乱码过渡到新标签；辅助阅读始终使用真实标签，关闭动效时直接切换。浏览页右上角头像是个人页入口。
- 搜索输入框与头像均为 56dp 高，中心线对齐。输入框跟随共享头像的进度，位移包含输入框宽度与右侧留白，左边缘最终完全越过屏幕右侧。搜索范围行固定 48dp，使大号页码与分类页保持相同高度。
- 所有堆叠卡片向视口底部外延长 160dp，大幅上滑时叠加有阻尼的整体拉伸（最大 120dp），松手通过现有弹簧归位。屏幕外冗余不扩展页面可滚动长度，避免上拉时露出底部空白。
- 分类页、搜索页和个人页统一露出主卡上部约 70%，使用同一可见比例常量。分类和搜索按完整卡片高度计算队列位置，使主卡 70% 高度处落在屏幕底边；不缩小卡片、不在页面中间增加遮挡条。个人页用同一比例限制整页滚动终点，展示数量、屏幕外回弹冗余和阅读覆盖层规则不变。
- 分类、搜索、本人及其他作者主页的堆叠顶部间隔按标题度量统一：`34dp + 29sp × 70%`，字号缩放参与计算，后排露出标题第一行约 70%，不再随结果数或容器高度改变。此比例与前卡整体露出 70% 是两项独立约束；首页圆弧不改变。其他作者主页直接复用个人页的堆叠、滚动裁切和上提阅读。
- 拖动和回弹期间，浏览页面的层级为：主圆最高（覆盖层 2），整组堆叠卡片其次（覆盖层 1），其他页面元素在下方。只抬高主圆自身，不抬高它的整个导航区域或其他悬浮控件。队列不受文章区、LazyColumn 或路由父容器的局部裁切，仍受屏幕物理边缘裁切。停稳后回到原绘制位置，个人页的裁切视口与滚动终点不变。覆盖层只接管绘制，不新增全屏触摸层；上提阅读使用独立覆盖层。

## 历史曲面参考及边界

- 下列曲面代码与参考测试保留作历史对照，不再是首页或分类的当前入口效果。

- 使用整张卡片的绘制快照建立 12×48 网格，并按圆柱曲面计算顶点投影；不是只拉伸封面 UV，标题、正文、轮廓随同一网格弯曲。
- 静止约 5° 侧视；滚动经过顶部弯折区，以及切换时的收卷，共用曲面计算。
- 快照在内容 / 主题变化时更新，不在每个动画帧读回位图。封面模糊纹理预先计算，正文不模糊；封面始终存在。
- **这是原生曲面首版，不是最终三维渲染验收。** 当前厚度 / 背面使用同网格暗色偏移层，没有独立的立体背面、侧壁及完整深度遮挡；与设计稿实体厚度和自遮挡仍有差距。
- 搜索与作者等普通结果列表不强行套用实体收卷，不复制文章凑循环数量，不自动滚动。

## 连续性与可访问性

- 主圆长按不添加全页模糊、蒙白或调暗。卡片自身的曲面封面模糊不影响页面背景。
- 深色页面 / Sheet 落点保持 #191a1c；主题过渡不先清成白色。
- 导航和搜索状态随原有返回栈恢复；进入层级页清焦点和隐藏输入法，避免重建后键盘抢先消费返回。
- 应用内页面关闭预见性返回的手势进度预览：在各路由内部处理确认后的系统返回，再播放既有返回动画。分类、搜索、我的统一通过首页导航入口返回，同步更新主圆页面状态并触发 400ms 图标形变和颜色过渡；二级页退回上一层，阅读页沿用卡片回收。抽屉、展开的小圆菜单和未保存编辑的返回处理仍优先于页面返回。首页返回桌面交由系统处理。
- 登录页进场尚未结束时确认系统返回，先完成进场，再执行 400ms 表单右滑退场，并同步切换主圆。取消手势不改变页面。
- 监听系统动画开关。关闭后跳过星芒开屏、曲面、圆形扩散、滑动与布局动画；日期、页面、焦点和内容直接到达目标状态。
- 外拉固定入口与主圆位置编辑分开；保留辅助功能的固定 / 收回快捷入口操作。
- 不人为延迟示例表单或离线状态，不将动效当成真实认证 / 上传 / 文章保存完成的证明。

## 仍需后续验收

- 120Hz 真机上的帧耗时、内存和长时间滚动；当前只运行约 60Hz 的 API 37 模拟器，验证 120Hz 请求与交互，不宣称稳定 120fps。
- 分类波浪队列在真机上的牵引手感、快速换向及长时间循环；历史曲面的实体背面 / 侧壁限制仍保留，不将其作为当前分类效果验收。
- 真机系统返回手势的确认与取消：取消不切页，确认后走应用返回动画，并同步更新主圆。
- 异形屏与折叠屏上的主圆 / 快捷圆布局；现有安全区限界不等于完整设备矩阵验收。
