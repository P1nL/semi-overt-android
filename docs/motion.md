# Android 动效首版

首版实现日期：2026-10-17；首页弧形队列 / 分类波浪堆叠更新：2026-10-19；统一卡片上提、个人页与场景进退场更新：2026-10-20。首页保留弧线构图，分类、搜索文章和个人公开文章共享卡片与上提阅读能力，不恢复旧眼睑开场。

## 全局 120Hz 目标

- 统一目标为 120Hz：主 Activity 的窗口刷新率请求、Compose 根节点、全部 ModalBottomSheet 及历史曲面参考场景的底层 Surface 使用同一 `MotionFramePolicy.TARGET_FPS`。旧系统仅请求当前分辨率支持的最接近且不超过 120Hz 的模式；新系统提交 120Hz 请求，由系统选择实际模式。
- 动画按系统 VSync 与经过时间推进，不新增忙循环 / 8ms 定时器，不加速原有导航、页面、主题或开屏时长。静止内容不为凑帧而持续重绘；系统关闭动画的行为保持。
- 未登录开屏改用原生矢量用户图标，不再加载旧的 90 帧 PNG 图集。600ms 弹跳按用户提供的 SVG 关键帧、分段 ease-in-out 和显示帧时钟采样，不依赖位图帧率。
- 圆环和用户轮廓在局部 2× 分辨率的透明蒙版中抗锯齿绘制，先按整像素 2:1 滤波降采样，再放到实际的亚像素位置；两个缓冲区按最大尺寸复用，归位缩小时不逐帧分配，不对全屏做超采样或模糊。取消头像外层重复圆形裁切，保留描边边缘的半透明覆盖；颜色、粗细、位置和原有时间线不变。
- 这是刷新率请求，不是硬件或持续性能保证；显示模式、系统调度、省电策略与帧耗时仍决定实际显示帧率。当前 API 37 模拟器仅提供约 60Hz 模式，不能据此宣称稳定 120fps。

## 已接入的流程

| 范围 | 当前行为 |
| --- | --- |
| 主圆 | 系统长按后其他入口以低刚度、轻微回弹的弹簧分批展开 / 回收（阻尼比 0.78、刚度 160，展开错峰 40ms、收起错峰 35ms）；连续承接中途速度，确认合并完成后才导航，不再使用 150–250ms 的快速收束 |
| 主圆页面图标 | 首页、分类、搜索、我的四个图标之间的六组双向切换统一使用 400ms 原生轮廓形变；形变状态保留在页面外层，新页面接管或返回时承接当前轮廓，中途换目标也不先跳到端点。主圆底色、尺寸和单份 6dp 阴影保持不动；阅读进退仍由共享阅读进度驱动，小圆合入编排不变 |
| 导航方向 | 随主圆左、中、右位置改变；一次手势布局固定，保留可点击导航和辅助功能替代操作 |
| 固定快捷圆 | 未选中的静态小圆与主圆同色，整圆 34dp 命中 / 静态范围连续换选，选中起保持目标页面色，已固定入口不重复展开。首次外拉为 20dp 空行程 / 216dp 分离，只执行一次 120ms 移向指针，不画连线；同次按住继续拖动直接跟手，不重启动画或外拉迟滞，松手不追加延迟。独立圆回收在 84dp 内形变，可见轮廓相切后用 180ms 缓入缓出长出短液态连接，填充与外投影同步，再拉开 18dp 间隙才断开；75dp 内松手临界阻尼融合，主圆在独立圆之上、不变换也不跳页。独立圆在路由外常驻，以固定根容器的绝对指针坐标驱动图层平移；长按不变色、松手保持落点，切页不重建独立圆，不改变主圆记录的页面 |
| 一级场景 | 各页保留原场景编排；旧页退场后半段与新页进场重叠，新旧页使用独立进度，详见 [跨页转场协调](cross-page-motion.md) |
| 首页 | 等大卡片沿贴左的平缓圆环循环；仅点击后向右上方展开，能原地展示就不移动队列，越界时最小让位；展开才触发近邻 20°、次邻 6° 倾斜，层级始终按文章顺序不变；无文件夹标签 |
| 分类文章流 | 手动波浪浏览不变；换分类时前景先退出、后排先进场；每张卡片各有 1000ms 位移，加 180ms 错峰，进退场各 1180ms；进场后半段保留小幅弹性惯性，在同一时间窗口内回稳 |
| 搜索 | 进退场统一为输入区与单卡各 750ms，加 150ms 错峰，场景共 900ms；共享头像同步使用 750ms（涉及未登录个人页时仍为 450ms）；文章按分类全屏基准计算尺寸，在结果区裁切；作者结果保持原行布局，范围横滑仍为 300ms |
| 阅读 / 层级页 | 首页与堆叠卡片均以单一进度展开阅读；文字先落位、头像后淡入、正文最后从底部上升，返回反向播放；其余层级页统一使用 500ms 缓入缓出的右侧滑入 / 向右滑出，背景联动位移与淡化使用相同曲线及时长 |
| 阅读主圆 | 移除顶部返回 / 目录按钮和底栏；主圆切换为目录图标，短按打开目录；长按展开首页、分类、搜索、我的四个小圆，来源页不被当作“当前页”排除，左 / 中 / 右位置分别适配四入口布局；外拉固定快捷入口保持，系统返回执行反向转场 |
| 阅读页主动切页 | 通过主圆选择主页面后，阅读页整页向下滑出屏幕，400ms 缓入缓出，无阅读页淡出；目标页在下方承接原有进场，系统返回的原卡片反向动画不变 |
| 阅读主圆图标形变 | 首页 / 分类 / 搜索 / 个人图标与目录图标通过六组对应轮廓连续插值，不再叠放两个图标交叉淡化；复用原生 Canvas 与原图标端点绘制，路径只在创建时采样，逐帧复用 Path。内部图标进度与正文阶段一致，返回反向还原，无独立播放计时器；进入阅读及返回原卡片期间，主圆本体始终不透明并固定在原位，不参与淡入淡出、缩放或卡片运动；页面交接时仅由最新挂载页面绘制一份主圆，避免两份 6dp 阴影短暂叠加闪烁；尺寸、触控和其他小圆不变，不引入 WebView 或 JS 图标库 |
| 登录 / 注册 | 从来源页右侧滑入，取消或普通返回时向右滑出（统一 500ms 缓入缓出）；成功进入演示身份后向下滑出（600ms），弹出账号页并返回实际来源页，来源页原位显露，不再固定跳转个人页；关闭系统动画时直接完成 |
| 日历 | 400ms 展开 / 收起、箭头同步旋转；同一个绿色选中底形在日期间弹性移动，首次选中 / 取消均柔和淡化；日期格取消不透明默认底色和灰色点击波纹 |
| 日期详情 | 容器 400ms 柔和展开 / 收起并淡化绿色背景；选中其他日期时保持展开，只将旧数据向左移出、新数据从右接续进入，容器高度连续适配；不再从日期格拉伸底形或在切换时先归零收起 |
| 抽屉 | 导航、阅读目录、年月、Diff、确认共用 SoBottomSheet，展开 / 收起统一 400ms 缓入缓出；按钮、系统返回、遮罩点击和下拉关闭均先完成收起再回调，保留安全区、滚动与辅助关闭操作 |
| 开屏 | 未登录：500ms 黑色粗线描圆、560ms 图标从圆内底部升至中心，肩线到位后保持不动，仅头部做 600ms 分段弹跳，随后 580ms 整体归位与背景扩散同步；无紫色填充，深色主题只反相为白线。已登录：描圆后等待头像快照就绪，再按网页个人页相同的整图像素算法细化 750ms，最后保留 580ms 归位；返回和 Activity 重建不重播 |
| 细节 | 首页主题按钮触发 760ms 圆形扩散（同网页曲线），太阳／月亮轮廓 220ms 形变；跟随系统的外观更新保留 220ms 颜色过渡、表单错误高度连续变化；页面状态预览仅保留主文本和图标，300ms 交叉淡入淡出，使用状态选项切换恢复，不再显示副说明和独立重试按钮；其他按钮 / 开关保留原生反馈 |

系统启动页使用与应用一致的浅 / 深色背景，Android 12+ 用透明占位图替代默认启动器图标，并在系统交接时立即移除，不追加退场动画。自定义开屏等待系统启动页交接（无启动页时等待 Activity 进场完成）后才从第一帧计时，不让系统加载阶段消耗描圆或像素动画的时长；系统关闭动画时仍直接显示内容。

冷启动先完整绘制描圆，未登录图标随后立即升起并播放头部动效，不再等待首页。登录时只挂载与页头相同的轻量头像来源，独立取得绘制快照并准备像素档位，不依赖完整导航；像素段仍等真实图片就绪后才计时。完整图标 / 头像绘制完成后再挂载导航和首页，避免首次构建打断前面的动画；准备期间保留完整身份图形，不停留在空圆环。首页在后台解码其所需封面，封面就绪后才构建卡片，并直接复用已解码图片，不再经 `painterResource` 在 UI 线程重复解码；阅读展开也复用这些图片，不把解码成本转移到第一次阅读。仅背景展开与整体归位等待页面和卡片已布局、首页封面及真实头像锚点已就绪；不等待被遮挡 / 离屏内容的绘制回调，也不以露出空页面来缩短首帧指标。返回、Activity 重建和关闭系统动画不新增这段等待；现有各动画段时长、头像落点、卡片几何与交互不变。

登录态像素段对齐网页 `pixelResolution`：整图中心裁成正方形，从 4×4 开始，按 cubic-out 驱动的 2 的幂次分辨率细化至最终尺寸，放大时使用最近邻采样，不再使用 8×8 逐格遮罩或六档线性采样；图像淡入、描边淡出也按网页像素阶段的相对时间执行。位图档位在后台一次准备好后才开始计时，不在逐帧绘制时缩放分配。当前图片来源仍是原生离线演示头像的绘制快照，不包含网页账号或头像接口接入；个人页封面的旧遮罩效果不受影响。

启动前与图标完成后的等待：冷启动在 `Activity.onCreate` 就启动首页示例数据 / 封面的后台预加载，首页直接等待并复用同一个任务，而不是动效结束后才开始解码；Activity 重建和系统关闭动画时不额外启动该预加载。启动体验使用非调试的 `preview` 构建，继承 Release 的完整优化并使用本机 debug 签名；Debug 构建用于调试 / 自动化测试，不作为正式启动速度判断依据。以上只调整初始化工作与构建方式，500ms 描圆、560ms 升起、600ms 头部动效、750ms 像素段、580ms 归位以及首页进场时长均不变。

## 首页弧形叠放卡片队列

- 右侧作者头像（2026-10-23）：圆形左缘与静止中卡右缘相切，直径按右侧留白计算（右侧留 12dp，上限 76dp），独立于卡片内容。外层透明，圆内使用当前首页背景色；本地示例继续使用已有头像占位图形，不新增远程照片数据。
- 浏览头像改为手势周期控制（2026-10-24）：取消半隐藏及 7 / 6 / 4 速度分段。超过原 touch slop、真正开始拖动后，头像用 140ms 向右退场一次；整个拖动期间保持隐藏，中途减速或按住不动都不恢复，轻触不触发退场。途中经过的作者不挂载、不补播。
- 松手后，同一中间卡片连续稳定 120ms（窗口内位移不超过 0.025 卡位），且收束中已接近整数停靠位（距离不超过 0.08 卡位），才用 280ms 滑入最终作者；无需等弹簧尾巴完全结束。恢复后不再因余动重复收起，下一次拖动重新开启确认周期。头像入场中再次拖动时，从当前位置平滑退回；作者图片只在屏外替换，不让旧头像重新进场。浏览态在点击展开（含先让位）、阅读与页面离场时收起；无动画 / 横屏等原列表回退不变。
- 点击展开的作者头像：卡片保持原尺寸、原右侧 16dp 位置与升起轨迹；升起到 95% 后，被点击卡片的作者头像以 280ms 从右侧进入，不受浏览态稳定窗口影响。头像右缘对齐展开卡片右缘，优先放在卡片上方，间隔 14dp；顶部安全区不足则放下方，两侧都不足时不遮盖内容或导航。上下位置在本次升起开始时确定，退场期间也不跳位。开始拖动、点击另一张卡片或进入阅读时，旧展开头像用 140ms 向右退出；回到浏览后使用上述手势周期。头像在卡片层后方，不拦截拖动，外层透明、圆内使用首页背景色。

- 主导航进场 1180ms：每卡完整运动 1000ms，错峰跨度 180ms；从左上沿手动下滑所用的同一弧线数学进入中部 / 下半部，最终真实排序第一篇停在焦点。主导航重新进入时恢复到第一篇；阅读返回及 Activity 重建保留原选择。
- **首页卡片退场为 900ms（0.9s）**，独立于分类与阅读时长。从当前相位继续向下运行，下半部先离场，上半部跟随；跨页时从第 450ms 接入目标页进场，旧页保留至轨迹完成，不倒放入场，不用淡出替代轨迹。

- 点击展开（2026-10-21）：滚动焦点与展开状态分离，停在中间不自动上升、右移或触发倾斜。点卡片才向右上方抽出，右侧留 16dp；上升量按它与前一层卡片的间距计算，靠位移露出完整内容，不提升 zIndex、不遮挡原本在前面的卡片。一次只展开一张，点击另一张会收回旧卡；开始滚动立即取消展开目标。卡片顶部不添加标签。
- 首页升起阴影的高度、环境阴影透明度与投射阴影透明度都绑定同一升起进度；卡片本体不再叠加固定阴影，因此回落全程同步淡出，不在终点突然移除。
- 原地优先：先检查抽出后的卡片能否完整放入顶部安全区加 76dp、底部系统安全区加 86dp 与主圆位置预留之间。能放下则队列位置完全不变；否则沿原弧线仅移动到最近合法位置（320ms 单调让位），不强制居中，然后展开。让位和普通滚动阶段不触发倾斜。
- 展开时的近邻绕自身底边做 X 轴三维倾斜：第一邻卡 ±20°、第二邻卡 ±6°，更远卡片不倾斜；上半段后倾、下半段前倾，主卡保持正面。保留原卡片尺寸、基础圆环及文章顺序；不压扁、不放大卡片，不添加选中边框。
- 当前卡片宽度通常为屏宽 70%，最大 360dp，按新参考改为方形、圆角 18dp；结合内容区高度限制保证整张卡片可见。封面铺满卡片，白色标题、作者 / 阅读时长与发布日期集中在底部，不再分隔彩色正文区、摘要或头像行。底部是同一封面的渐进高斯模糊，不是渐变压暗蒙层；模糊预处理在两张离线 WebP 中，不在滚动帧中实时生成。示例沿用原创森林 / 建筑插画，原无封面的文章按原卡片色调复用相应主题封面；并非新增实拍照片。顶部入口与导航主圆不参与队列运动；顶部栏和底部提示均无背景遮罩，卡片可延伸到它们后方，仅在屏幕边缘裁切。
- 11 篇原创示例按原文章顺序循环，上滑选择后面的文章，下滑选择前面的文章，最后一篇可继续到第一篇。每篇文章有稳定身份，不在切换途中换图；同一帧不重复绘制同一篇。基础圆弧保持中心 `(0.48w, 0.53h)`、半径 `(0.30w, 0.34h)`、角步长 `0.30`，`|distance|≤4` 内不添加退场位移。停稳仍为中间一张及前后各四张。首尾离屏路径在第 4 到第 5 个卡位间用 smoothstep 平滑展开，不再挤在最后 0.35 个卡位；下一停靠位置前整张离屏并停止绘制，不额外露出第六个位置的卡片，不用透明度掩盖循环，双向运行一致。
- 内容区均可上下滑动；位移直接跟随纵向手势，横向手势不换卡。释放速度影响有限的续滑距离，并以最多 2.2 页 / 秒的初速度进入弹簧；dampingRatio 0.82、stiffness 105，柔和低刚度配合高阻尼，只保留克制的越位回弹，不做反复跳动或立方体姿态摆正。不增加圆环 / 假卡片背景，非选中卡片仍按文章顺序叠放。
- 只有主动展开时才有主卡上移、邻卡逐级响应；邻卡使用三维前后倾斜而非平面旋转，不额外平移。倾斜使用独立弹簧并随距离降低刚度。主卡的两个位移轴使用同一 0–1 弹簧进度；主队列原有收束参数不变，不重排文章。
- 使用系统 touch slop 避免轻触被当作滑动；半页交界处留 0.06 页的焦点迟滞，减少来回抖动。新的拖动可以中断收束并从当前画面继续，不排队播放旧动作。离开场景时丢弃邻卡弹簧余动，首尾循环的不可见卡片不携带旧动画重新出现。
- 第一次点击只展开，不进入阅读；展开完成后再次点击进入阅读。阅读返回及 Activity 重建保留队列的实际位置（包括最小让位产生的小数位置），不自动展开。离开场景时取消未完成收束，从实际可见位置接续向下退场，不先跳回整数卡位。
- 使用原生 Compose 卡片、主卡 translationX / translationY、邻卡 rotationX / TransformOrigin(0.5f, 1f) 与轻量 shadowElevation；cameraDistance 为卡片像素高度的 8 倍，rotationZ 保持 0、缩放保持 1，不提升选中层级。数据保留 11 篇稳定身份文章，只组合原圆弧及尚未完全离屏的末端卡片，首尾回收发生在屏幕外，不创建首页 EGL Surface，也不生成文章位图快照。
- 辅助功能提供阅读、上一篇 / 下一篇及显式定位。系统关闭动画、字体大于 1.2 倍、横屏或内容区过矮时使用原可读列表，不恢复旧立方体或曲面首页。

## 分类波浪堆叠

- 当前时长内每篇文章只绘制一次，按文章身份保持首尾循环。保留各卡片原来的顶部位置与叠放高度，只向下延长卡片至视口底部，不把整组卡片下移；前后排等宽，滑动中也不做远小近大的缩放，文字保持同样字号，不用纵向拉伸文字来填充。卡片只保留顶部圆角，底边为直角；标题、作者与日期整体放在卡片左上角，距边缘 18dp。页码仍位于内容区右上方。封面外观复用首页已有组件，分类不改变首页的位置 / 层级 / 卡片样式；首页的独立弧形波浪规则见上节。
- 卡片宽度为内容区的 90%（上限 420dp，仍受短屏尺寸约束），加宽不改变原顶部位置与纵向层叠间距；分类独立封面只在最底部约 12% 做轻量渐进模糊，上方保持清晰，首页封面不变。素材由 `tools/generate_category_covers.py` 离线生成，无滚动帧实时模糊。
- 参考网页端 `HomeShowcaseRail.vue` 的波峰 / 邻卡联动：前卡直接跟手，后排从同一帧开始响应，不再等待位移阈值。在连续队列位移外叠加明显波峰，第一、第二邻卡的波峰目标按网页 0.25 / 0.10 衰减，再向更深处继续衰减；每张卡片用独立的可重定向 Compose 弹簧跟随目标，形成近强远弱的起伏，而非整组刚性平移。不照搬网页的横向展开和旋转，保留移动端等宽纵向排列与底部连接。前卡完全越过屏幕底部后，才在不可见阶段切换到最后方，并清除旧波峰余动。
- 下滑位移与释放速度采用 1.25 倍增益，同等队列位移所需下滑行程约缩短 20%；上滑的手势行程标尺保持不变。跟随直接映射当前手势，不用延时任务逐张启动；快速换向立即反映到整条波形，不回放排队动画。
- 上滑沿同一连续路径反向运行：前排逐张升高，运行到后排的卡片向下回落，形成前升后降的波形。反向拖动不重置各卡片位置，也不另起一个排队动画；只由手势与松手余动驱动，不自动循环。
- 松手主队列保留 dampingRatio 0.86 / stiffness 95 的柔和厚重弹簧；邻卡波峰按网页 stiffness 120 / damping 25 / mass 1 换算为 Compose stiffness 120 / dampingRatio 1.14，独立跟随、平缓回落，换向直接重定向，不排队。只做 Compose 平移与层级变化，不增加第三方动画依赖、逐帧截图 / 背景实时模糊或分类 EGL Surface。
- 各阅读时长分别保存已确认的文章位置；阅读返回、Activity 重建与时长轮换恢复相应位置。共享转场开始时取消未完成拖动 / 收束并恢复最后确认的位置。
- 辅助功能提供上一篇 / 下一篇、明确文章定位与阅读。系统关闭动画、字体大于 1.2 倍、横屏或可用高度不足时退回可读列表；空筛选保持原空状态，不重新启用旧曲面。

## 同款卡片上提与个人页（2026-10-20）

- 分类、搜索文章、个人页公开文章统一全封面、上 18dp 圆角 / 下直角、顶部信息及底部短模糊。卡片内部居中短横线为 32×3dp，实际命中区 96×48dp；所有可见位置的卡片均可从把手上提阅读，普通点按后排卡仍用于选中。提交阅读时将该文章保存为队列前卡，返回落到其新的前景位置；短提取消不改变原选择。
- 超过 8dp 且向上位移大于横向的 1.2 倍才接管阅读手势，不劫持普通队列滑动。主要行程 160dp，超出后逐渐增加阻力；45% 松手或有效向上速度达到 900dp/s 提交。松手速度仍参与提交判定，但不再注入确认展开；短提取消仍承接松手初速度使用原阻尼弹簧。
- 拖动阶段封面、标题、文字信息和把手作为整张卡片共同平移、轻微放大，不提前拆散内容。手指行程仅占前段进度，松手后才继续扩展为阅读容器；后段仍按文字到位、头像淡入、正文从底部上升的顺序呈现。保留源 / 目标固定排版，避免缩放时换行。
- 确认展开固定为 1100ms 缓入缓出，从实际松手位置继续，不因快速上滑而缩短，也不产生展开过冲。背景容器保留缓入缓出，将展开窗口从 0.62–1.00 缩短为 0.62–0.94，让背景更快展开到位；整体时长、标题减速及头像 / 正文时序不变。退出阅读为 1300ms；拖动跟手与短提取消的原有弹簧不变，系统关闭动画时仍直接导航。

- 上提期间，阅读转场副本与其余堆叠卡片共用同一绘制平面，按原队列层级排序；后排卡原地提起，不越过前排。原本在前面的卡片保持可见并弹性下落，不因阅读副本进入全局覆盖层而被遮住。仅提交阅读后更新队列选择，返回时落到新的前景位置。
- 页头、头像、搜索范围与作者数、大号页码、个人信息 / 记录 / 栏目标题、快捷入口等非卡片元素，在上提行程中就开始淡出，取消时随回落恢复。主圆是例外：本体始终保持固定和不透明，不参与阅读进退场动画；只有内部页面图标与目录图标随进度连续变形。首页其余卡片仍保留淡出方案，不改为堆叠页的下落路径。
- 大号页码的透明度直接作用于完成定位后的数字行，包含分子、斜杠和分母；不在偏移前的外层边界上做淡出裁切，取消提起时连续恢复。
- 文字转场固定源、目标各自的排版宽度与字体尺寸，通过图层等比例缩放、位移和两端排版交叉淡化完成；不逐帧插值文本排版宽度 / 字号，不再在行程中反复触发换行。日期分隔符也保留在固定的目标文本中，不在中途拼接跳变。

- 拖动和回弹期间，浏览页面的层级为：主圆最高（覆盖层 2），整组堆叠卡片其次（覆盖层 1），其他页面元素在下方。只抬高主圆自身，不抬高它的整个导航区域或其他悬浮控件。队列不受文章区、LazyColumn 或路由父容器的局部裁切，仍受屏幕物理边缘裁切。停稳后回到原绘制位置，个人页的裁切视口与滚动终点不变。覆盖层只接管绘制，不新增全屏触摸层；上提阅读使用独立覆盖层。

## 历史曲面参考及边界

- 下列曲面代码与参考测试保留作历史对照，不再是首页或分类的当前入口效果。

- 使用整张卡片的绘制快照建立 12×48 网格，并按圆柱曲面计算顶点投影；不是只拉伸封面 UV，标题、正文、轮廓随同一网格弯曲。
- 静止约 5° 侧视；滚动经过顶部弯折区，以及切换时的收卷，共用曲面计算。
- 快照在内容 / 主题变化时更新，不在每个动画帧读回位图。封面模糊纹理预先计算，正文不模糊；封面始终存在。
- **这是原生曲面首版，不是最终三维渲染验收。** 当前厚度 / 背面使用同网格暗色偏移层，没有独立的立体背面、侧壁及完整深度遮挡；与设计稿实体厚度和自遮挡仍有差距。
- 搜索与作者等普通结果列表不强行套用实体收卷，不复制文章凑循环数量，不自动滚动。

## 连续性与可访问性

- 主圆长按不添加全页模糊、蒙白或调暗。卡片自身的曲面封面模糊不影响页面背景。
- 深色页面 / Sheet 落点保持 #191a1c；主题过渡不先清成白色。
- 导航和搜索状态随原有返回栈恢复；进入层级页清焦点和隐藏输入法，避免重建后键盘抢先消费返回。
- 监听系统动画开关。关闭后跳过像素开屏、曲面、圆形扩散、滑动与布局动画；日期、页面、焦点和内容直接到达目标状态。
- 外拉固定入口与主圆位置编辑分开；保留辅助功能的固定 / 收回快捷入口操作。
- 不人为延迟示例表单或离线状态，不将动效当成真实认证 / 上传 / 文章保存完成的证明。
