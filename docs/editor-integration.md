# 移动端编辑页

首页展开主圆后，点击“创建草稿”进入编辑页。固定为独立小圆的创建入口也进入同一编辑页。
编辑器覆盖在当前页面上，返回时保留首页卡片、滚动位置和主圆位置。
创建入口先等待草稿小圆全部收起并绘制完成，再挂载编辑器；编辑器就绪后播放液态入场。
独立创建入口在草稿菜单展开时使用同一收起流程，菜单关闭时直接进入；收起中重新展开菜单会取消待执行的创建。

点击“草稿箱”时，蓝色小圆从当前位置延展为圆角大气泡，草稿列表在轮廓展开后显现。
固定在页面上的草稿箱快捷圆也从自身位置展开。列表文字保持原字号与换行，不随气泡拉伸。
联网模式合并当前账号的云端草稿和本机待同步草稿，离线演示只读本机草稿。
列表显示标题、状态、退回原因、保存时间和字数；
尚未输入内容时显示空状态，点击十字图标创建草稿。点击条目先将气泡收回按钮，再继续编辑同一篇草稿。
点空白处、关闭按钮或系统返回键均收起气泡。关闭动态效果时直接切换。

气泡顶部用单行“n篇草稿”显示数量。紧凑列表使用 2dp 圆头滚动条，只绘制滑块，轨道透明。
条目左滑后露出 64dp 垃圾桶区域；松手后按位移与速度吸附，超过边界时提供阻尼，
点击垃圾桶才删除。竖向手势继续滚动列表，同一时间只展开一条删除操作。
每篇草稿使用独立本机存储键；打开条目恢复对应正文，删除后重新打开草稿箱仍保持删除结果。
模拟器示例可用 `DraftBoxPreviewSeedTest` 和 instrumentation 参数 `seedDraftPreview=true` 补入 12 篇，
已有草稿内容保留，示例不会在应用启动时自动补回。

## 加载与复用

应用启动时通过 AndroidX WebKit 异步启动内核，与首页网格共用启动结果；支持分段启动的 WebView 会把主线程初始化拆成短任务。预热不创建编辑器页面。
首次创建仍在草稿小圆收起后挂载 WebView，并等待脚本和首帧就绪，再播放 950ms 液态转场。
导航宿主持有一个编辑器实例；退出后保存草稿、清理临时气泡和编辑焦点、脱离视图树并暂停，
再次进入时复用文档与撤销历史，同步当前主题和键盘位置，完成首帧确认后再入场。
宿主销毁时保存并释放该实例。`EditorEntryPerformanceTest` 记录不含转场的就绪耗时，
同时检查重复进入不新建 WebView、不重载脚本，以及正文、标题、摘要和撤销历史的连续性。

## 编辑功能

编辑资源随 APK 打包，从 WebViewAssetLoader 的本地 HTTPS 域名加载，不依赖电脑上的 demo 服务。
保留原 demo 的 Tiptap 内核、网页端 Markdown 格式、工具自定义、摘要、封面、预览和本机自动保存。
系统选图用于正文图片和封面；Markdown 导出使用系统文件保存界面。
首次点击发布校验标题和正文（至少 50 个非空白字符，不计 Markdown 标记），短文仍可自动保存。
进入预览后标题位置不变，提示气泡显示「进入预览」；工具栏向下滑出 300ms，字数淡出 150ms，
标题下展开当前账号的头像、昵称、本地日期和预计阅读时间。退回编辑时反向播放。

网页资源位于 `app/src/main/assets/editor/`。`native.css` 去除原型手机外框及模拟状态栏，
`native.js` 处理系统返回、离开前保存和前景运动通知；`app.js` 的存储键支持 `draftKey` 参数。
当前编辑稿保存在应用 WebView 的账号专属存储中，返回再进入会继续恢复。
输入停稳后自动尝试云端同步。三点菜单只提供 Markdown 导出和舍弃；舍弃已同步的草稿也会删除云端副本。
检测到云端版本冲突时保留本机正文，可在「处理同步冲突」中读取云端或另存草稿。
预览里的弹射按钮支持点击或拉满确认环后松手，直接保存当前版本并送审。短拖松手只回弹。
送审成功后保持只读预览，
从该页返回时执行编辑器退场。待审核可撤回后继续编辑；退回后显示审核原因。
联网模式选入正文或封面的图片先上传，再把服务端 URL 写入文档。
点击标题、正文或弹窗中的文本框可输入；格式工具、光标控制、抽屉展开/收起和校验提示不主动唤起键盘。
更多菜单和文本操作气泡支持出现、消失与中途反向切换动画。
内部滚动、CSS 和 Web Animations 通过 `SemiNative.motion()` 续期高刷请求，通知间隔至少 100ms；动画检测只在交互或动画事件后运行，结束即停止。原生宿主只接收当前挂载编辑器的通知，静止后沿用全局 400ms 释放策略。
工具抽屉展开时点标题或正文会自动收起；编辑中展开抽屉会隐藏键盘。
键盘出现不缩短编辑区，而是抬起底部工具栏和字数栏；正文保留完整滚动空间，自动让当前光标可见。

图片工具直接打开系统选图。表格在光标处插入居中的 3×3 无表头网格，上方气泡调整行列与表头，
打勾完成后长按表格进入选择；可切换行、列、单元格，并拖动两端手柄调整范围。
行向下添加、列向右添加；删除按当前选区执行，单元格模式清空内容、整表模式删除表格。
链接工具使用光标旁的链形标记和上方网址气泡；先选文字或进入链接状态后输入文字，再填网址打勾。
临时链接范围属于编辑器装饰，不写入保存的 Markdown。
链接进入待确认状态即点亮工具图标，再次点击取消；标题工具从当前按钮上方展开正文与 H1–H5 紧凑菜单。
光标方向键支持长按连续移动，选择/退出选择沿用项目 280ms 乱码过渡，辅助阅读始终使用完整文案。
键盘关闭后操作工具栏保留真实编辑焦点、光标与选区，仅通过 `inputmode="none"` 抑制软键盘；
再次直接点击文本输入区恢复原输入模式。键盘已打开时工具栏保留输入状态，展开抽屉则隐藏键盘并保留正文光标。
键盘升起后工具栏阻止平移手势，顶部功能行缩为 42px；收起状态整体高度为 122px。

标题、正文、摘要和网址使用原生文字绘制，保留系统输入、中文组词及选区操作。
表格插入、规格变化及选区边界平滑过渡；删除最后一行或一列会直接删除整表。
列操作逐格动画，在表格总宽度不变时也平滑调整列宽。工具栏按 WebView 与键盘的实际屏幕重叠定位，正文滚动不会平移工具栏。

编辑内核源码与构建入口位于 `tools/editor-engine/`，复用相邻网页项目的编辑依赖及 Markdown 适配器。
设置 `SEMI_WEB_ROOT` 指向该网页项目后运行 `node tools/editor-engine/build.cjs`，生成 APK 使用的本地 bundle 和依赖许可文件。

### 定向验证

`ArticleEditorIntegrationTest` 覆盖编辑入口、键盘与抽屉互斥、编辑区高度、图片入口、表格选区及增删、链接和草稿恢复。
键盘位置用例在专用模拟器上使用普通底部键盘：临时设置 `show_ime_with_hard_keyboard=1`、
`stylus_handwriting_enabled=0`，运行后恢复原值。Gboard 浮动手写工具条不提供底部键盘高度。
用例为测试宿主设置与主 Activity 一致的 edge-to-edge 和 `adjustResize`。

## 液态进入与返回动画

采用 GSAP Dynamic Morphing 的双层波浪，从屏幕底部向上揭示编辑页，完整过程最多 950ms。
编辑器完成脚本初始化和首帧绘制后才开始上升；转场结束前屏蔽编辑触摸。
保留示例的 10 个横向控制点、`power2.inOut` 节奏和横向中点三次曲线。
按屏幕宽高分别控制随机点延迟和层间错峰，单层波峰与波谷的高差最多为屏幕宽度的 50%，
起伏更明显，双层之间仍保持紧凑，避免竖屏上出现细长拉丝。波形沿用 1450ms 参考时间轴计算，
实际播放压缩为 950ms，进入与反向返回使用同一速度倍率，保持各进度下的轮廓不变。
前层浅色使用色卡的亮琥珀 → 秋叶橙（`#FFCF10` → `#EB641B`），暗色使用青绿 → 蓝
（`#118480` → `#1F50D5`），后层直接揭示编辑页；每次进入生成一次延迟，帧间不重新随机。
原生裁剪路径按屏幕宽高映射，结束前覆盖全屏，不再使用中心圆点或径向扩散。
返回时沿同一条路径反向下降，退场结束后才关闭编辑页。入场中返回从当前进度倒放，不重新生成波形。
减少动态效果时直接显示和关闭页面。效果结束后移除遮罩，正文和光标始终不参与形变。

## 浅暗色主题

编辑器跟随 App 主题，页面、工具抽屉、摘要/封面、文本操作气泡、弹窗和预览共同切换。
主题在首帧前通过 `theme` 参数设置；页面打开后通过原生桥同步，无需重载或重建草稿。
编辑器和 App 使用同一套浅暗色主色：浅色青绿 `#118480`，暗色薄荷绿 `#2CB38B`。小字号链接按背景调整亮度，错误提示使用色卡的番茄红系。
工具栏、工具抽屉和操作气泡采用浅暗色中性半透明玻璃，保留模糊、细边和柔和阴影；
工具背景与文字保持中性，仅选中图标、自定义图标和状态圆点使用主题绿。

### 检索与选型

检索分别覆盖 Compose 液态转场、SVG 有机遮罩、噪声径向揭示，以及 Android 原生图形接口：

- InkFlow：最接近中心墨水扩散的 Android 实现，Apache-2.0。
  https://github.com/felixny/InkFlow
  固定参考提交 `12ff525a5b597874f1ae4adbee6bc4d4cb4ed648`。
  初版参考其径向揭示思路；当前已改用从底部上升的原生波浪路径。
- CircularReveal modifier：支持圆形揭示，但规则圆边缘不符合本次要求。
  https://gist.github.com/lub0s/64745eab9faa61cba73afd6e6f20b96b
- Organic Shape Animations：SVG 有机遮罩的相近视觉参考，适合网页；未引入其代码。
  https://github.com/codrops/OrganicShapeAnimations
- Dynamic Morphing：控制点错时推进与 `power2.inOut` 节奏的视觉参考。
  https://demos.gsap.com/demo/dynamic-morphing/
  https://codepen.io/GreenSock/pen/qBedXpg
  Android 保留示例曲线，以原生裁剪实现双层向上揭示；竖屏按宽高压缩点延迟和层间错峰。
- Android 官方 AGSL 与本地 WebView 内容加载说明：
  https://developer.android.com/develop/ui/views/graphics/agsl/using-agsl
  https://developer.android.com/develop/ui/views/layout/webapps/load-local-content

原 demo 保留在独立可视化目录；Android 使用项目内打包资源。
