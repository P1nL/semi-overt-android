# 浏览页 WebGL 背景

首页、分类、搜索和登录后的个人主页共用一份本地 WebGL 曲线网格。构建脚本从相邻网页仓库的 `src/widgets/app-background/AppBackground.vue` 提取顶点着色器和几何数据生成函数，使用同一份 OGL 依赖打包。

画板保持居中，占屏宽 90%、屏高 80%；曲线可以自然越过画板边缘。浅暗主题均使用黄色 `#FFDD13` 的内侧星芒，曲线、边框和上下两排圆点仍为秋叶橙 `#EB641B`。

曲线和边框使用 2.3 CSS px 的连续描边，边缘渐变宽度按线条方向调整。内侧连接点使用尖端跨度 8 CSS px 的四角星芒，上下边缘保留直径 4 CSS px 的圆点，两种轮廓均使用渐变抗锯齿。Android 画布按设备像素比渲染，上限为 1.8×，与网页端独立。

背景在浅暗主题下均按 30 fps 节拍播放。每次绘制后，等下一次绘制时刻临近再请求 `requestAnimationFrame`，实际绘制仍跟随屏幕同步。冷启动时，应用异步预热 WebView 内核，星芒开屏无需等待。视图和网格在开屏背后准备；穿越星芒前若网格尚未就绪，最多等 500ms。首页首次进场完成后再循环播放背景，后续浏览页复用同一个渲染器。

打开阅读、编辑器、登录或设置等非浏览页时取消等待和已请求的动画帧，最后一帧留在后台，不显示于这些页面；返回浏览页后从该帧续播。App 离开前台时同样暂停。系统关闭动画时，浏览页显示静态画面。背景不接收触摸、焦点或无障碍焦点。

登录后的个人页展开记录时，原有曲线网格保持清晰并继续播放。

资源、OGL 和其授权文件均随 APK 打包，不依赖网络加载：

```powershell
node tools/web-background/build.cjs
.\gradlew.bat :app:assemblePreview --console=plain
```

默认使用同级目录 `../semi-overt` 的源码和已安装依赖；其他位置可通过 `SEMI_WEB_ROOT` 指定。修改网页端背景后，先重新运行打包脚本，再构建 APK。

`WebHomeBackgroundTest` 覆盖两种主题的橙色线条与播放、触摸穿透、记录展开时保持清晰，以及设置、登录和阅读的后台停帧与续播。
